### Interactive Portfolio Enhancements

## Project Description

This project is my personal portfolio website, developed for Lab 2 in Javascript for Web Development. The project extends my Lab 1 portfolio with an interactive and accessible feedback form on the Contact page.


## Grade target

Grade 3

## Implemented features

* Feedback form with added functions that gives the user immeniate feedback on their input.
* Live character counter for the message field
* Error messages and visual feedback for invalid and valid field.
* Personalised success message after a valid form submission
* Clear button that resets the form and validation feedback
* Responsive design for mobile and desktop

### How to run the project

1. Open the project folder in Visual Studio Code.
2. Open Portfolio/Contact.html
3. Start the page with Live Server.
